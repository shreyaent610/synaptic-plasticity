Core Claim

Temporary Hebbian strengthening enables a neural network to form short-term, context-specific memories. These memories decay with time and can be modified or overwritten by new activity.

What is happening inside the model?

The network has a stable baseline structure. When neurons become active together, their connection receives a temporary Hebbian boost. That boost acts as a short-lived memory trace rather than a permanent learned weight.

1. Form

Activate a pattern. Co-active neurons temporarily strengthen their mutual connections.

2. Recall

The strengthened pathway makes the recently active pattern easier to reactivate.

3. Forget

Without reinforcement, temporary strengthening decays toward the baseline state.

4. Interfere

New patterns can compete for the same neural resources and reshape the temporary memory state.

Explorable Model: Ask the Network Questions

The simulation is also a small experimental model. Change parameters and observe how memory lifetime, interference and context specificity change.

Question 1

How long does memory survive?
Increase or decrease the decay rate and repeatedly advance time.

Question 2

What causes interference?
Store A, then B. Adjust similarity and interference to test whether memories coexist or compete.

Question 3

How fast can a trace form?
Change the Hebbian learning rate and compare the immediate strength of new memories.

Suggested Hackathon Experiments

  1. High learning rate + low decay → strong, persistent short-term traces.
  2. High decay → rapid forgetting.
  3. High context similarity + high interference → stronger competition between memories.
  4. Low similarity + moderate interference → greater context separation.

Scientific Framing

Conceptual update rule:

Temporary traceij(t+1) = (1 − decay) × traceij(t) + learning × activityi × activityj

The permanent baseline can remain unchanged while the temporary trace evolves. This is the distinction demonstrated by the project: memory can exist in transient activity-dependent synaptic states.
