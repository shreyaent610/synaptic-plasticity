Core claim

Temporary Hebbian strengthening enables a neural network to form short-term, context-specific memories. These memories decay and can be modified or overwritten by new activity.

What is happening inside the model?

Normally, we think of a neural network's connections as fixed while it processes information. This project demonstrates the alternative: what if the connections themselves temporarily change as information arrives?

What changes?

Neural activity changes immediately. More importantly for this demonstration, a temporary synaptic trace changes as neurons are active together.

What stays fixed?

The model has a stable baseline network. The toy experiment does not train new permanent weights with backpropagation.

Where is memory?

Short-term memory is represented by transient activity-dependent connection strength that can later decay.

What can erase it?

Time causes decay. A new, similar context can also compete with and reshape the existing temporary state.

The BDH Connection

This section connects the project's central idea to the BDH-related framing: information can be represented by temporary state changes rather than only by permanent parameter updates.

Conceptual claim: Recent activity can change connections, allowing those connections to temporarily store information.

In the toy model below, the transient trace is the memory-bearing state. This makes the idea observable: store a context, advance time, introduce another context, and watch the temporary state change.

traceij(t+1) = (1 − decay) × traceij(t) + learning × activityi × activityj

Interpretation: co-active neurons increase their temporary connection trace; decay pulls that trace back toward baseline. This is a simplified educational rule, not the official BDH equation.

Why it matters

The experiment separates memory in transient connection state from permanent learning. That is the key idea this BDH-related module is designed to make intuitive.

Honest limitation

This is a simplified educational simulation and not the official BDH model. It uses a small hand-designed network and simplified rules; it does not reproduce a full architecture, training procedure, biological mechanism, or benchmark result.

Scientific framing & experiment questions

How long does memory survive?

Set a decay rate and repeatedly press Advance Time. Lower decay should make the simulated trace persist longer.

What causes interference?

Store A, then B. Increase context similarity and interference to make the toy memories compete more strongly.

How fast can a trace form?

Change the learning rate and compare the immediate memory strength after storing a context.

Suggested demonstration

  1. Store A and observe the brightened temporary edges.
  2. Advance time several times and watch A decay.
  3. Store B and increase similarity/interference.
  4. Explain that the changing quantity is the temporary synaptic trace, not a newly trained permanent network.
